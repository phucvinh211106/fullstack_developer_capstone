
# Cars Dealership - Full Stack Development Capstone

A full-stack web application developed as part of the IBM Full Stack Software Developer Capstone Project.

## Project Overview

Cars Dealership is a web application designed to help customers explore car dealerships, view dealer information, read reviews, and submit their own reviews.

## Technologies

- Python and Django
- React and JavaScript
- HTML and CSS
- Node.js and Express
- MongoDB and SQLite
- Docker and Kubernetes
- IBM Cloud Code Engine
- GitHub Actions

## Features

- User Registration and Login
- Browse Car Dealerships
- Filter Dealerships by State
- View Dealer Details and Reviews
- Submit Dealer Reviews
- Sentiment Analysis
- Responsive Frontend

## Project Structure

- server/djangoapp - Django application
- server/djangoproj - Django project configuration
- server/frontend - Frontend
- server/database - Database-related code
